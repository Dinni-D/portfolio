# Personal Portfolio Website

A simple one-page portfolio website built with plain **HTML** and **CSS**. It presents my skills, data analytics projects, experience and education.

## Sections

- About me
- Skills
- Projects (Shopping App Reviews Dashboard, Healthcare Analytics Dashboard, Sentiment Analysis)
- Experience
- Education
- Contact

## Built with

- HTML5 (semantic tags: `header`, `main`, `section`, `footer`)
- CSS3 (fonts, colours, spacing, borders, cards)

## Project structure

```
portfolio/
├── index.html   # page content
├── style.css    # page styling
└── README.md    # project description
```

## How to run

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## What I learned

- Structuring a web page with semantic HTML
- Styling with CSS (box model, colours, typography)
- Linking a stylesheet and creating internal and external links
- Organizing a project in a GitHub repository
